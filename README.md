# VacationRentalPMS.com

Lead-generation website foundation for vacation rental property management software.

## Goals

- Capture high-intent vacation rental PMS leads
- Build SEO landing pages around property management software intent
- Keep deployment simple and framework-independent
- Provide a clean base for future product/demo pages

## Local preview

Open `index.html` directly in a browser, or run any static file server.

## Structure

- `index.html` - homepage
- `styles.css` - design system and responsive styles
- `script.js` - lightweight interactions
- `robots.txt` - crawler rules
- `sitemap.xml` - initial sitemap
- `.gitignore` - common ignored files
